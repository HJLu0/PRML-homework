# 关于分类算法性能分析的实验报告

## 摘要

本实验聚焦于复杂三维特征空间中的模式识别问题，通过构建并对比决策树（Decision Trees）算法、AdaBoost 集成学习以及支持向量机（SVM）等多种经典机器学习模型，系统性地评估了各算法在非线性空间划分任务中的拟合能力与泛化表现。

实验不仅通过准确率、精确率及召回率等量化指标对模型进行了多维度评价，更核心地利用 Marching Cubes 算法将抽象的数学决策逻辑转化为具象的三维决策曲面。实验阶段的深度观察显示，数据的空间分布具有高度的非线性与局部嵌套特征，这对算法的拓扑建模能力提出了严峻挑战。

实验数据表明，AdaBoost + Decision Trees 通过残差学习与权重迭代机制，在 3D 空间内构建了极度精细的非线性边界，实现了极高的分类精度。SVM 在 RBF 核函数的支持下，展示了优异的数学连续性，测试准确率同样较高，能够生成平滑的包围式超平面。相比之下，基础决策树虽然表现稳健，但在边界拟合的细腻度上略显不足；而线性 SVM 则受限于核函数表达力，在非线性处理能力上表现出明显的局限性。

**关键词：** 决策树、AdaBoost 集成学习、SVM 算法

---

# 1 引言

在机器学习领域，如何在高维特征空间中寻找最优超平面以实现精准分类，是决定模型性能的关键。三维空间数据（X、Y、Z）由于其具备直观的几何拓扑特性，成为研究分类器决策边界形态的理想实验场。本实验旨在探讨当数据分布不再满足线性可分假设时，不同算法如何通过数学变换或集成策略来逼近真实的物理边界。

通过对比单模型、集成模型及基于内核映射的判别模型，我们将深入分析偏差与方差在三维空间任务中的权衡，并阐述算法从底层公式到空间几何划分的演变过程。这种从抽象代数到直观几何的转化，对于理解机器学习模型的决策逻辑至关重要。

---

# 2 数据处理

实验采用的数据集通过 `make_moons_3d` 算法生成，模拟了空间中相互嵌套的非线性分布结构。实验共生成 1000 个样本作为训练集（C0 与 C1 类各 500 个），并另行生成同分布的 500 个样本（两类各 250 个）作为测试集，以保证模型评估的严谨性。

在预处理阶段，首先利用 `pandas` 库载入 X、Y、Z 三个连续型数值特征并进行数据清洗，确保无缺失值干扰。随后，程序执行了关键的类别映射，将原始文本标签 `C0` 和 `C1` 转换为数值 `0` 和 `1`，以适配 `scikit-learn` 框架的计算要求。

为了保证 SVM 等基于距离度量的算法不因特征量纲差异产生偏差，实验通过数据生成机制确保了输入特征均处于同一数量级，维持了特征空间的几何稳定性。在可视化层面，原始数据点被绘制在三维坐标系中，通过颜色区分真实类别，为后续评价模型生成的“预测外壳”与“原始点云”的贴合度提供了参考基准。

# 3 决策树分类

## 3.1 决策树算法原理

决策树是一种非参数化的监督学习方法，模型通过递归地对特征空间进行轴向切分来降低样本集的不确定性。其数学核心是信息熵，定义公式为：

```math
H(S)=-\sum_{i=1}^{n}p_i\log_2(p_i)
```

其中，$p_i$ 代表样本属于第 $i$ 类的概率。在每一个节点，算法通过遍历特征 X、Y、Z 寻找最优切分点，使得切分后的子集信息熵之和最小。

算法执行上，本实验采用了 `DecisionTreeClassifier`，并将最大深度限制为 6。这种深度限制能够有效防止决策树在细枝末节过度生长导致过拟合。在实际的 3D 空间中，决策树的切分逻辑表现为一系列相互垂直的超平面。这些平面将空间分割成一个个矩形盒子，每个盒子内部的样本被归为同一类。

## 3.2 结果分析

实验结果显示，决策树取得了 0.9060 的训练准确率和 0.8900 的测试准确率，两类样本的 F1-score 均为 0.89。

![图 1 决策树分类结果](图1.png)

在可视化图像中，决策树的边界表现为一系列绝对垂直或水平于坐标轴的平面，将空间切割成一个个独立的“决策盒子”。虽然这种方法具有极强的规则解释性，但由于其只能进行轴向切分，在面对非轴向分布的圆润边界时，会产生明显的“锯齿效应”，导致其测试准确率在所有模型中处于较低水平。

# 4 AdaBoost 决策树分类

## 4.1 集成学习算法原理

AdaBoost 是一种迭代式集成算法，它以深度较浅的决策树为基学习器，在训练过程中不断调整样本权重，使后续的弱分类器能够专注于前一轮被错误分类的样本。

从 3D 可视化的物理角度看，AdaBoost 的决策边界不再是生硬的单一盒子，而是由数百个具有不同权重和位置的平面叠加而成，最终形成一个能够紧密贴合数据分布的复杂非线性曲面。这种集成机制显著降低了模型的偏差，使其在处理精细的空间扰动时具有极强的拟合能力。

最终的分类决策函数为：

```math
F(x)=\operatorname{sign}\left(\sum_{m=1}^{M}\alpha_m h_m(x)\right)
```

其中，$h_m(x)$ 是第 $m$ 个弱分类器，$\alpha_m$ 是其对应的权重。这种机制使得模型能够不断修正之前的决策偏差。

实验配置了 200 个迭代周期的 AdaBoost 架构，以深度为 5 的决策树为基学习器，学习率设定为 0.1。通过这种级联式的训练，AdaBoost 实际上在 3D 空间中叠加了数百个位置微调的平面。这些平面在加权求和后，在 Marching Cubes 算法的可视化下呈现出极其精细且复杂的曲面，能够紧密地贴合点云的边缘。

如图所示，结果训练集准确率达到了完美的 1.0000，测试集准确率也高达 0.9720。在 3D 空间图中，其生成的复杂曲面能极其精准地捕获点云中的微小嵌套，展示了极强的局部拟合能力。

# 5 SVM 分类

## 5.1 SVM 算法原理

支持向量机的目标是在高维空间中寻找一个能够最大化类间间隔的超平面，其性能高度依赖于核函数对数据的拓扑映射能力。

### 线性核（Linear Kernel）

线性核函数的公式为：

```math
K(x_i,x_j)=x_i\cdot x_j
```

它不改变数据的维度，直接在三维空间中寻找最优切分平面。由于本实验数据在三维空间内呈现非线性扭曲，线性核只能画出一张绝对平坦的斜面。可视化图中可见大量数据点位于平面错误的一侧，这表明线性模型在处理此类复杂空间任务时存在明显的欠拟合。

### RBF 核（高斯核）

RBF 核函数公式为：

```math
K(x,z)=\exp\left(-\gamma\|x-z\|^2\right)
```

它将每个支持向量映射为高维空间的一个感应中心，计算样本点与中心点的欧氏距离。实验中 RBF 核可视化结果非常独特：它生成了圆润、平滑的球形或椭球形包围面。这种边界在数学上具有极佳的连续性，不像集成树那样细碎，在物理分布建模中更具稳健性，是处理点云类聚类数据的极佳选择。

### 多项式核（Polynomial Kernel）

多项式核函数为：

```math
K(x,z)=(\gamma x\cdot z+r)^d
```

它通过特征的幂次组合映射增强模型表达能力。虽然它比线性核更灵活，但在 3D 空间中，多项式边界往往沿某些主成分方向产生剧烈扭曲或无限延伸。对于本实验这种局部聚簇的数据，多项式核的适应性不如 RBF 灵活，容易在数据边缘产生误判。

在本次实验中，线性核（Linear Kernel）的表现最为受限，其测试准确率仅为 0.6800，因为它只能在 3D 空间寻找一个平直的切分面，对于非线性数据产生了严重的欠拟合。

相比之下，径向基核（RBF Kernel）展现了强大的局部映射能力。RBF SVM 的训练与测试准确率分别达到 0.9740 和 0.9760，生成的决策边界表现为平滑且闭合的 3D 外壳。

此外，多项式核（Polynomial Kernel）虽然优于线性核，测试准确率达到 0.8680，但其边界往往沿某些方向产生不稳定的延伸，对点云状聚类数据的适应性不如 RBF 自然。

# 6 结论与分析

各个算法的训练集、测试集准确率如下表所示：

| 准确率 | Decision Trees | AdaBoost + Decision Trees | Linear Kernel | RBF Kernel | Polynomial Kernel |
| --- | -------------- | ------------------------- | ------------- | ---------- | ----------------- |
| 训练集 | 0.9060         | 1.0000                    | 0.6670        | 0.9740     | 0.8650            |
| 测试集 | 0.8900         | 0.9720                    | 0.6800        | 0.9760     | 0.8680            |

在处理本实验中这种高度非线性的 3D 点云嵌套数据时，算法的表现本质上取决于其对空间拓扑结构的建模逻辑。

* **SVM（RBF Kernel）** 表现最优，因为其径向基核函数通过高维映射，在原理上将每个支持向量视为一个感应中心，构建出基于欧几里得距离的径向对称决策场，天然契合点云的非线性聚簇特性。
* **AdaBoost** 表现优秀则源于其集成学习的纠错机制，通过串行迭代不断调整样本权重，将数百个弱决策平面的预测结果进行非线性加权聚合，从而精准逼近复杂的物理边界。
* 相比之下，单棵决策树受限于其固有的轴向对齐切分逻辑，只能在空间中生成阶梯状的矩形边界，难以平滑拟合曲率较高的非线性曲面。
* 线性 SVM 仅能在原始空间寻找单一的平直超平面，在面对空间结构扭曲且相互渗透的数据分布时，完全丧失了界定复杂拓扑边界的数学表达能力。

---

# 7 实验总结与反思

本实验全面评估了多类分类器在三维空间中的表现。实验证明，对于复杂的空间分布数据，AdaBoost 集成算法凭借其卓越的残差拟合能力，是追求极致分类精度的最佳路径。同时，SVM 配合 RBF 核函数展示了在非线性空间中构建平滑连续边界的独特优势，在测试集表现上甚至微优于集成模型。

基础决策树与线性 SVM 则分别因模型结构简单和数学表达受限，难以完全胜任高度非线性的 3D 分类任务。通过 3D 可视化技术对算法逻辑的具象化展示，我们更深刻地理解了机器学习模型从抽象数学公式到具象空间几何划分的转变本质，为未来复杂空间数据的模型选择提供了科学的参考依据。
