# 关于线性拟合与非线性拟合的实验报告
## 摘要
本实验主要研究线性及非线性拟合问题，首先采用最小二乘法、梯度下降法、牛顿法完成线性模型 y=ωx+b 的拟合实验，系统分析三种算法的核心原理、收敛特性及误差表现的差异性；针对线性模型无法捕捉数据非线性特征导致拟合效果不佳的问题，分别构建三频三角函数模型与kernel核模型进行非线性拟合，对比两种模型的拟合精度与工程实用性，最终选择kernel核模型作为最优拟合方案。

实验结果表明：线性模型下最小二乘法与牛顿法收敛至全局最优解，梯度下降法受超参数影响存在微小偏差，三种算法MSE均约0.6，拟合能力受限；三频三角函数模型虽能捕捉数据周期特征，MSE有所下降，但存在模型泛化能力弱、参数调优复杂等问题；kernel核模型通过核技巧将数据映射至高维特征空间，无需人工预设函数形式，训练集与测试集MSE均显著降低，且泛化能力、拟合灵活性优于三频三角函数模型。

**关键词**：最小二乘法；梯度下降法；牛顿法；三频三角函数模型；kernel核模型

## 一、引言
在数据科学与工程建模的回归拟合任务中，算法选择与模型架构设计是决定拟合效果的两大核心因素，而模型架构的合理性对拟合结果的影响远高于算法本身。针对二维非线性回归数据，单一线性模型因无法捕捉数据的非线性、周期性特征，往往拟合效果不佳；而非线性拟合模型的选择则需兼顾拟合精度、泛化能力与工程实用性。

本实验围绕数据集展开两阶段拟合研究：第一阶段采用最小二乘法、梯度下降法、牛顿法三种经典优化算法完成线性模型拟合；第二阶段针对数据的非线性特征，分别构建三频三角函数模型与kernel核模型进行非线性拟合。

## 二、评价指标
实验采用**均方误差(MSE)**作为模型拟合效果的核心量化指标，MSE反映模型预测值与真实值的平均平方偏差，数值越小表示拟合精度越高，计算公式为：
MSE = (1/n) * Σ(从i=1到n) (yi - ŷi)²

其中n为样本数量，yi为第i个样本的真实值，ŷi为模型对第i个样本的预测值。

实验分别计算各模型在训练集与测试集上的MSE，综合评价模型的拟合精度与泛化能力；同时结合**模型灵活性**、**参数调优难度**、**工程实现复杂度**作为定性评价指标。

## 三、线性模型拟合实验
### 3.1 三种线性算法的收敛特性分析
1. **最小二乘法**：无迭代过程，通过正规方程直接求解全局最优解，收敛性与数据无关，只要特征矩阵XᵀX可逆，即可得到唯一最优解，收敛结果稳定，无超参数影响。
2. **牛顿法**：利用海森矩阵包含的二阶导数信息，对目标函数进行二次泰勒近似，收敛速度为平方级，仅需少量迭代即可收敛至全局最优解，收敛效率远高于梯度下降法，且受超参数影响小。
3. **梯度下降法**：仅利用一阶梯度信息，收敛速度为线性级，收敛结果受学习率与迭代次数影响显著：学习率过小会导致收敛缓慢，学习率过大会导致参数震荡不收敛，迭代次数不足则无法逼近最优解，易出现局部最优或参数偏差。

#### 结果分析
1. 最小二乘法与牛顿法的拟合参数、MSE完全一致，验证了线性模型下最优解的唯一性，两种算法均能收敛至全局最优。
2. 梯度下降法的拟合参数存在微小偏差，训练集MSE略高于前两者，测试集MSE则较低，体现了超参数对梯度下降法的影响。
3. 三种算法的MSE均约0.6，拟合精度较低，且拟合直线仅能捕捉数据的整体上升趋势，无法反映局部周期性波动，表明线性模型的表达能力与本实验数据的特征不匹配，**模型架构的局限性**是拟合效果不佳的核心原因。

## 四、非线性拟合实验
### 4.1 模型构建与原理
#### 三频三角函数模型
结合数据的周期性波动特征，构建线性和三频三角函数复合模型。通过人工预设的函数形式匹配数据的线性与周期特征，利用曲线拟合算法求解最优参数，属于**参数化非线性模型**，拟合能力依赖于人工预设的函数形式是否与数据特征匹配。

#### kernel核模型
无需人工预设函数形式，核心原理为：通过核函数将低维非线性可分数据映射至高维特征空间，在高维空间中实现线性回归，从而间接解决低维空间的非线性回归问题。

实验选择**高斯核(RBF)**作为核函数，其表达式为：
K(xi, xj) = exp(-γ||xi - xj||²)

其中，γ为核函数带宽，是模型核心超参数；同时引入岭回归的正则化参数α，抑制模型过拟合，提升泛化能力。

### 4.2 模型训练与拟合结果
#### 三频三角函数模型
三频三角函数拟合采用曲线拟合算法对模型参数进行优化，设置最大迭代次数200000，精度1e-12，通过多次调参得到最优参数。
- **拟合方程**：y = 0.157354x - 0.953438sin(2.403886x) + 0.273360cos(2.403886x)
- **拟合图像**（图4）：纵轴数值范围-2.0~2.0，横轴数值范围0~10，图中包含训练集散点、测试集散点及拟合曲线
- **误差表现**：训练集MSE为0.347961，测试集MSE为0.347813。

#### kernel核模型
kernel核模型选择高斯核为核函数，通过网格搜索对超参数γ与α进行寻优。
- **拟合图像**（图5）：纵轴数值范围-2.0~2.0，横轴数值范围0~10，图中包含训练集散点、测试集散点及核拟合曲线
- **误差表现**：训练集MSE为0.318295，测试集MSE为0.331016，总体低于三频三角函数拟合法，表明kernel核模型更适合用于该拟合问题。

## 五、实验总结与反思
本实验根据二维数据集，完成了线性模型的三种算法拟合与非线性模型的两种方案拟合，系统分析了不同算法、不同模型的拟合效果与核心特性。实验结果表明，**kernel核模型**通过核技巧实现了非线性数据的高精度拟合，其拟合精度、泛化能力、灵活性均优于其他模型，是本实验的最优拟合方案。

1. 回归拟合的本质是对数据背后生成规律的挖掘，**模型架构的合理选择**是挖掘数据规律的核心，而算法优化仅为辅助手段。在工程实践中，应摒弃重算法、轻模型的误区，先通过数据特征分析选择匹配的模型架构，再选择合适的优化算法与超参数调优方法，才能实现高效、稳定的回归拟合。
2. 超参数调优是提升模型性能的关键，无论是梯度下降法的学习率、还是kernel核模型的核带宽与正则化参数，超参数对模型效果均有显著影响；工程中应采用贝叶斯优化、网格搜索等**自动化的超参数寻优方法**，而非人工试错，提升调参效率与模型性能。
